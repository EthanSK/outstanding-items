The whole idea

Four useful things. No productivity theatre.

+

Captures every ask

Main tasks, corrections, side thoughts, and unrelated reminders all stay on the list.

↺

Shows it every reply

You always get a compact view of what is open, waiting, parked, and done.

→

Suggests one next move

When it helps, the agent recommends one sensible next step. It does not start it.

✓

Keeps a full ledger

Long lists open in a clean local editor where you can edit, reorder, complete, and undo.

#1

The rule that matters

The list belongs to you.

Adding, sorting, or recommending an item never gives the agent permission to work on it. Nothing starts until you explicitly ask.

How it feels

Talk. See the list. Choose.

  1. Talk normally.Do not stop to organise your thoughts.
  2. Get the ledger back.Every request has a stable ID and an honest status.
  3. Start what you want.Say “start OI-2” when you are ready. Until then, it waits.

Install

One script. No dependencies.

Clone the repository, preview exactly what will be installed, then install it for Codex, Claude Code, or both.

Requires only sh and python3. Installation starts no service and opens no port.

git clone https://github.com/EthanSK/outstanding-items.git
cd outstanding-items
sh scripts/install.sh --dry-run
sh scripts/install.sh
