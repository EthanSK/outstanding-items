The whole idea

Four useful things. No productivity theatre.

+

Captures every ask

Main tasks, corrections, side thoughts, and unrelated reminders all stay on the list. The agent adds its own only when a useful loose end would otherwise be lost.

↺

Shows it once per turn

Two or three lines at the end of the final answer. Never repeated through progress messages.

→

Suggests one next move

Those lines name a single item worth doing next — no list, no counts, no done pile. It does not start it.

✓

Keeps a full ledger

Everything else waits in a clean local editor where you can edit, reorder, complete, and undo. Transferred work stays folded away with its destination task named.

#1

The rule that matters

The list belongs to you.

Adding, sorting, or recommending an item never gives the agent permission to work on it. Nothing starts until you explicitly ask.

How it feels

Talk. See the list. Choose.

  1. Talk normally.Do not stop to organise your thoughts.
  2. Get one suggestion back.Every request has a stable ID and an honest status; one of them ends the answer.
  3. Start what you want.Say “start OI-2” when you are ready. Until then, it waits.

Install

Pick your agent. Install the same skill.

The repository follows both plugin formats while keeping one canonical skill underneath.

No service starts and no port opens. The standalone skill installer remains available in the README.

# Codex
codex plugin marketplace add EthanSK/outstanding-items
codex plugin add outstanding-items@outstanding-items

# Claude Code
claude plugin marketplace add EthanSK/outstanding-items
claude plugin install outstanding-items@outstanding-items --scope user
