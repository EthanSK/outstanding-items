The whole idea

Four useful things. No productivity theatre.

+

Captures every ask

Main tasks, corrections, side thoughts, and unrelated reminders stay on the list. Any real loose end you still need to look at is added as Agent; nothing is invented just to fill the page.

↺

Shows it once per turn

Two or three lines at the end of the final answer. Never repeated through progress messages.

→

Suggests one next move

Those lines name a single item worth doing next — no list, no counts, no done pile. It does not start it.

✓

Keeps a full ledger

Everything else waits in a clean local editor where you can edit, set a lasting manual order, complete, and undo. Double-click an item to keep its reminder note open, then double-click again without moving the pointer to close it. Project chats keep separate private ledgers in the project's Git-ignored `.outstanding-items/` directory by default. Automatic items surface by actionability and recency without overwriting your dragged positions. Each chat refreshes an outdated editor from the installed plugin while preserving its local link. Proven finished work moves to completed automatically. Transferred work stays folded away with its destination task named.

Install

Pick your agent. Install the same skill.

The repository follows both plugin formats while keeping one canonical skill underneath.

No service starts and no port opens. Each harness installs the plugin through its own marketplace.

# Codex
codex plugin marketplace add EthanSK/outstanding-items
codex plugin add outstanding-items@outstanding-items

# Claude Code
claude plugin marketplace add EthanSK/outstanding-items
claude plugin install outstanding-items@outstanding-items --scope user
